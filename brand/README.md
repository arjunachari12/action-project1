# Mishi & Nivin — Brand Assets

This folder contains vector and raster logo assets for the Mishi & Nivin brand.

Contents
- SVG (editable):
  - `mishi-nivin-icon-1080.svg` — Instagram-ready round icon (MN monogram)
  - `mishi-nivin-wordmark-horizontal-dark.svg` — Wordmark for dark backgrounds
  - `mishi-nivin-wordmark-horizontal-light.svg` — Wordmark for light backgrounds
  - `mishi-nivin-wordmark-stacked.svg` — Stacked version for square formats
- PNG (exports):
  - Sizes included alongside each SVG: 1080, 512, 256, 128 (icon) and 1600/1200/800 (wordmarks)
- Favicon:
  - `favicon.ico` — multi-size 16/32/48/64px

Brand tagline
- "KIDSWEAR • WOMENSWEAR"

Usage
- Instagram profile: use `mishi-nivin-icon-1080-1080.png`.
- Website header (light): `mishi-nivin-wordmark-horizontal-dark-1600.png` on dark sections.
- Website header (dark): `mishi-nivin-wordmark-horizontal-light-1600.png` on light sections.
- Square placements: `mishi-nivin-wordmark-stacked-1080.png`.
- Favicon: place `favicon.ico` at your site root and reference in HTML:

```html
<link rel="icon" href="/favicon.ico" sizes="any">
```

Editing
- Prefer editing the SVGs in a vector editor (Figma/Illustrator/Inkscape). Re-export PNGs as needed.
- Colors: gradient from #FF8FB3 → #FF7AB6 → #7EB6FF; text is white on dark, charcoal (#151823) on light.
